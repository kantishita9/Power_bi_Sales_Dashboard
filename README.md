**E-Commerce Sales Dashboard Using Power BI**

**Project Overview**

This project is an interactive E-Commerce Sales Dashboard developed using Microsoft Power BI. The dashboard helps analyze sales performance, profit trends, customer purchasing behavior, product categories, and payment modes through dynamic visualizations.

The objective of this project is to transform raw sales data into meaningful business insights that support data driven decision making.

**Objectives**

* Monitor overall sales performance.
* Analyze profit trends across different periods.
* Identify top-performing product categories and sub-categories.
* Understand customer purchasing patterns.
* Compare sales performance across states.
* Track payment method preferences.
* Provide an interactive dashboard for business analysis.


**Tools & Technologies**

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* CSV Data Sources
* Data Cleaning & Transformation
* Data Modeling

**Dataset Information**

The project uses two datasets:

**Orders.csv**

Contains order related information such as:

* Order ID
* Customer Name
* State
* Category
* Sub-Category
* Quantity


**Details.csv**

Contains transaction details such as:

* Amount
* Profit
* Payment Mode
* Order Information


**Conclusion-**

This project demonstrates the use of Power BI for transforming raw business data into actionable insights. The dashboard provides an efficient way to monitor sales performance and supports informed business decisions through interactive and visual data analysis.
